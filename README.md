# ani-cli-ru (TUI)

`ui_tui.py` — теперь основное приложение в этом репозитории.
Это TUI на Textual для поиска релизов AniLibria, выбора эпизодов, просмотра стримов и скачивания серий.

## Основные возможности

- Поиск аниме по русскому или английскому названию
- Панель со списком эпизодов (выбор с клавиатуры)
- `Enter` в списке эпизодов: запуск выбранной серии
- Переключение качества: `best`, `1080p`, `720p`, `480p`, `360p`, `worst`
- Fallback качества (если выбранное недоступно)
- Скачивание выбранной серии (клавиша `d`)
- Короткие статус-сообщения в панели информации
- Тихий запуск плеера (без ffmpeg-логов в терминале)

## Текущая точка входа

- `ui_tui.py`

Legacy-скрипты в репозитории сохранены, но основной сценарий работы — через TUI.

## Требования

- Python 3.10+
- Python-пакеты:
  - `textual`
  - `httpx`
- Опционально (рекомендуется) плеер:
  - `mpv` или `vlc`
  - Также поддерживаются распространенные Windows-плееры (fallback: MPC-HC/MPC-BE/PotPlayer)
- Опционально для загрузок:
  - `ffmpeg` (для сохранения сразу в `.mp4`)

## Установка зависимостей

```bash
py -m pip install textual httpx
```

## Запуск

```bash
py ui_tui.py
```

## Управление

- `Enter`: воспроизвести выбранную серию (когда фокус на списке эпизодов)
- `d`: скачать выбранную серию
- `q`: переключить качество
- `[` / `]`: предыдущий / следующий эпизод
- `Ctrl+C`: выход

## Переменные окружения

- `ANI_CLI_API_BASE`
  - По умолчанию: `https://anilibria.top/api/v1`
- `ANI_CLI_QUALITY`
  - По умолчанию: `best`
- `ANI_CLI_PLAYER`
  - По умолчанию: `mpv`
- `ANI_CLI_DOWNLOAD_DIR`
  - По умолчанию: `./downloads`

## Примечания по воспроизведению

Приложение пытается запустить плеер в таком порядке:

1. `ANI_CLI_PLAYER` (если найден)
2. Распространенные установленные плееры (`mpv`, `vlc`, MPC, PotPlayer)
3. Fallback через системное открытие URL в Windows

Если выбранное качество недоступно, автоматически используется fallback-качество, это отображается в `Status`.

## Примечания по скачиванию

- Если установлен `ffmpeg`: сохраняется `.mp4`
- Если `ffmpeg` не установлен: сохраняется `.m3u8` playlist
- Путь сохраненного файла показывается в `Status`
