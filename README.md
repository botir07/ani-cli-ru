ani-cli-ru — CLI инструмент для просмотра и стриминга русского дубляжа аниме с AniLibria.

## Возможности

- Просмотр аниме с AniLibria
- Русский дубляж
- Удобный интерфейс командной строки
- Быстрая загрузка

## Установка

1. Клонируй репозиторий:
```bash
git clone https://github.com/botir07/ani-cli-ru.git
```

2. Запусти скрипт:
```bash
./ani-cli-ru.ps1
```

## Использование

Запусти скрипт и следуй инструкциям на экране.

## Требования

- PowerShell 5.1+
- Подключение к интернету
